# Banking Analytics Dashboard (Power BI)

## Project Overview
This project presents an interactive **Banking Analytics Dashboard** built using **Microsoft Power BI**.  
The dashboard analyzes banking transactions and customer account data to uncover insights related to branch performance, customer behavior, credit risk, and loan patterns.

## Objectives
- Analyze transaction trends and volumes
- Evaluate branch performance using composite metrics
- Understand customer loyalty and credit score distribution
- Examine loan behavior and risk indicators
- Deliver an executive-level, interactive dashboard for decision-making

##  Datasets
- **Banking Transactions Dataset** *(BankingDataset1)* : Transaction details such as type, amount, date, currency, branch code, and time
- **Customer Account Details Dataset** *(BankingDataset2)* : Account type, balance, interest rate, credit score, loan amount, and customer demographics


## Tools & Technologies
- Microsoft Power BI
- DAX Measures ,etc (Data Analysis Expressions)
- Power Query
- Excel (for data validation)

## Dashboard Pages
### 1️)  Banking Overview
- KPIs: Total Transactions, Total Customers, Transaction Value, Loan Amount, Credit Score
- Transaction trends over time
- Transaction distribution by city and transaction type,etc

### 2️) Transactions & Branch Performance
- Transaction count by branch
- Branch performance score (volume + value based)
- Transaction patterns by time of day
- Drill-down: Branch → Transaction Category,etc

### 3️) Customer, Loans & Risk
- Credit score distribution
- Loan amount vs credit score analysis
- Loan amount by employment sector
- Customer loyalty analysis (account tenure),etc

##  Key Insights
- Transaction activity remains stable with minor fluctuations over time
- A small number of branches contribute disproportionately to transaction volume and value
- Credit score distribution indicates a moderately low-risk customer base
- Loan amounts show a weak correlation with credit scores, suggesting multi-factor credit evaluation
- Long-standing customers represent strong customer retention

##  Features
- Interactive slicers (Branch, Account Type, Currency, Date)
- Drill-down analysis for deeper insights
- Tooltips for contextual information
- Clean, executive-friendly dashboard design
